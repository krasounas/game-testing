# 🐞 Bug Report – Tank Fu: Enemy Tanks Escape Arena

## Description
Enemy tanks in Tutorial Arena 2 move outside the circular combat zone and get stuck beyond the playable area. The player cannot damage or pull them back, causing a soft-lock.

## Steps to Reproduce
1. Start the tutorial.
2. Enter Arena 2.
3. Wait for enemy tanks to spawn.
4. Observe tanks moving toward the outer boundary.
5. Tanks exit the arena and become stuck.
6. Player cannot interact with them.
7. Tutorial objective never completes.

## Expected Result
Enemy tanks should remain inside the arena or automatically return if they leave the combat zone.

## Actual Result
Tanks leave the arena, get stuck, and block tutorial progression.

## Severity
High

## Platform
PC

## Build Version
Playtest build
